### 先に、このデータの限界を書きます

**空き状況は分かりません。** 公表データに入っていないからです。画面に出している「定員」は、いま受け入れられる人数ではありません。

**公表データから消えた事業所が、廃止したかどうかも分かりません。** 消えた理由（廃止・指定の取消・移転・登録の更新漏れ）までは公表されていないので、この道具は「公表データから消えた」としか書きません。

**公表件数が増えた＝事業所が増えた、でもありません。** 就労継続支援B型の公表件数は2021年11月の13,245から2026年3月の20,783まで増えていますが、これは自治体の登録が進んだぶんが混ざった数です。だから全国の増減は「公表された件数」と書き、事業所数とは言いません。

分からないものを分かったように書かない。それがこの道具の設計です。

---

### 何ができるか

**住所を入れると、通える範囲の事業所が近い順に出ます。**

| 収録しているサービス | 事業所数 |
|---|---|
| 就労継続支援A型 | 4,650 |
| 就労継続支援B型 | 20,783 |
| 就労移行支援 | 3,396 |
| 就労定着支援 | 2,038 |

2026年3月末時点、合計30,867事業所。**緯度経度が全件そろっている**ので、住所からの距離がそのまま出ます。定員・営業時間（平日／土／日／祝）・定休日・電話・事業所のサイトも表示します。

あわせて、次のページが最初から入っています。

- **都道府県ページ（47）** … 市区町村別の一覧表と、半年ごとの公表件数の推移
- **市区町村ページ（1,505）** … 事業所一覧・推移・消えた事業所。政令市と東京23区は**区ごとのページ**も
- **事業所ページ（30,867）** … 定員・連絡先・近くの事業所
- **CSV と JSON API** … `/data/offices.csv`、`/api?q=住所`
- **sitemap.xml・llms.txt** … 検索エンジンとAI検索の両方に向けた索引

### 「消えた事業所」を数える

就労継続支援A型は、2024年4月の報酬改定のあと、公表データから消える事業所が増えました。

| 最後に公表された時点 | 消えたA型 | その定員の合計 |
|---|---|---|
| 2024年3月末より後（改定後） | 889件 | 13,450人分 |
| それ以前（2021年11月〜2023年9月） | 342件 | 4,180人分 |

定員は、その事業所が最後に公表されたときの定員を足したものです。**そこで働いていた人数ではありません。**

全国の合計事業所数だけを見ていると、この動きは見えません。新しく開設した事業所が相殺してしまうからです。**番号が消えた数**で見ると、はっきり分かれます。

市区町村ごとに、消えた事業所の名前と「最後に公表された時点」が一覧で出ます。自分の市で何が起きたのかを、事業所名まで示して説明できます。

### なぜ要るのか

就労継続支援の事業所を探すとき、多くの人は市の福祉課に電話するか、事業所のサイトを1件ずつ開いています。国は全国のデータをオープンデータとして出していますが、**サービス種別ごとにZIPで分かれたCSV**で、住所から引ける形にはなっていません。

この道具は、そのCSVを住所から引ける形に変えただけです。ただし、変えるときに「分からないもの」を混ぜないようにしています。

### 置き方（3分）

1. `kshuro.php` と `kshuro_data/` を置く
2. その階層の `.htaccess` に `AddHandler php-script .php` を書く（共有サーバーの既定がPHP5.6のことがあるため）
3. `https://あなたのドメイン/kshuro.php/` を開く

**データベースサーバーも常駐プロセスもポートも要りません。** 必要なのはPHP 8とPDO SQLiteだけです（どちらも標準で入っています）。書き込み権限も不要です。

住所から緯度経度を出すのに国土地理院の住所検索を使いますが、つながらない環境では「取得できませんでした」と表示して止まります（「事業所がありません」とは書きません）。事業所の座標は最初からデータに入っているので、外部のジオコーディングサービスは要りません。**判定は置いた場所で完結し、外部のAIやAPIには何も送りません。**

### 更新のしかた（年2回）

WAM NETのオープンデータは毎年3月末・9月末に更新されます。同梱のPythonを2本動かせば、新しいデータベースができます。

```
python3 scripts/fetch_sfk.py --all
python3 scripts/build_db.py
```

### こんな方に

- **議員事務所・行政** … 自分の自治体で何か所が消えたのかを、事業所名つきで示せます。CSVはそのまま委員会の資料に使えます
- **相談支援事業所・障害者就労支援の関係者** … 利用者に「通える範囲にどこがあるか」を距離つきで見せられます
- **福祉系のメディア・支援団体** … 自分の名前で公開できます（MITライセンス）
- **自治体のDX担当** … 国のオープンデータを住民が引ける形にする例として、そのまま流用できます
